# consilient

Name reserved for **Consilient** — an open-source meta-harness for agentic work,
organised around measuring **β**, the rate at which automated checks accept a bad
artifact.

> "The Consilience of Inductions takes place when an Induction, obtained from one class
> of facts, coincides with an Induction obtained from another different class."
> — William Whewell, 1840

The project takes its name from that sentence; the package takes the adjective.

Pre-release. Nothing is published here yet; this package exists so the name refers to
the project rather than to whoever got here second. MIT.
